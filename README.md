# Dishsage 🍽️

**Dishsage** is a minimalist, user-friendly recipe website built on WordPress.com. It offers a curated collection of recipes for everyday cooking, emphasizing simplicity and accessibility.

## 🌐 Live Site

Visit the live website: [https://dishsage.wordpress.com](https://dishsage.wordpress.com)

## 📖 About

Dishsage provides:

- **Curated Recipes**: A selection of recipes catering to diverse tastes and dietary preferences.
- **"Ask Me Anything" Feature**: A central button guiding users directly to the complete recipe archive.
- **Responsive Design**: Ensures optimal viewing across devices, from desktops to smartphones.

## 🛠️ Built With

- [WordPress.com](https://wordpress.com/) – Hosting and Content Management System
- [Sage Theme](https://heartenmade.com/product/sage-wordpress-theme/) – A clean and modern theme tailored for food bloggers

## 📈 Future Enhancements

- **Search Functionality**: Implementing a search bar to allow users to find recipes by ingredients or titles.
- **Categorization**: Organizing recipes into categories for improved navigation.
- **User Interaction**: Adding features like comments and ratings for community engagement.
